# 🚀 CodeClub -> Code Daily

> **Learn. Code. Commit. Repeat.**

CodeDaily is a shared GitHub repository where each member maintains their own branch and commits their daily learning, code, notes, and projects. The goal is to build consistency and learn from each other's progress.

---

## 📌 Rules

### 1. One Branch Per Person

* Create a branch using your GitHub username.
* Work **only** on your own branch.
* Do **not** commit directly to `main`.

Example:

```
lokesh
vasco
Coder
```

---

### 2. Daily Commitment

Try to make **at least one meaningful commit every day**.

Your commit can include:

* 💻 Code
* 📝 Notes
* 📚 Resources
* 🧩 DSA solutions
* 🚀 Mini projects
* 🐛 Bug fixes
* ✨ Anything you learned

---

### 3. Commit Message Format

```
Day XX - Topic
```

Examples:

```
Day 01 - Git Basics
Day 07 - Binary Search
Day 15 - React Hooks
Day 30 - Docker Introduction
```

---

### 4. Folder Structure

Create a folder with your username and organize your work however you prefer.

Example:

```
your-username/
├── 2026-07-18/
│   ├── notes.md
│   └── solution.py
├── 2026-07-19/
└── ...
```

---

### 5. Respect Others' Work

* ❌ Do not modify files in someone else's folder.
* ❌ Do not push to another person's branch.
* ✅ Feel free to explore and learn from others' work.

---

### 6. No Pull Requests Required

Everyone maintains their own branch.

Unless announced by the repository owner:

* No pull requests.
* No merging into `main`.

---

## 🎯 Goal

The objective is **consistency**, not perfection.

Even if you only learned one new concept today, commit it.

Small daily progress beats occasional large efforts.

---

## 🌱 Motto

> **Learn. Build. Commit. Grow.**
